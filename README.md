# Análise de Vendas | Do dado bruto ao dashboard

Projeto de portfólio que percorre o ciclo completo de dados sobre uma
base de vendas de varejo: limpeza, análise, modelagem e visualização.

## 🎯 Objetivo
Responder perguntas de negócio como:
- Qual o faturamento e a margem por mês, categoria e região?
- Quais vendedores e canais performam melhor?
- Como o realizado se compara às metas?

## 📂 Sobre os dados
- **Fonte:** base fictícia de vendas
- **Período:** jan/2025 a set/2026
- **Tamanho:** 1779 linhas e 23 colunas antes da limpeza
- **Abas de apoio:** produtos, vendedores e metas

## 🗂️ Estrutura do repositório
- `data/raw/`: base original, sem alterações
- `data/clean/`: base tratada
- `docs/`: log de limpeza, prints e anotações
